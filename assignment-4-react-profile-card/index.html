React Profile Card

A single reusable ProfileCard component, rendered twice with different data passed in through props.

How it works

One ProfileCard component accepts name, role, image, bio and tags as props. The App component holds an array of people and renders one card per entry with .map(), so adding a new person never means writing new markup.
