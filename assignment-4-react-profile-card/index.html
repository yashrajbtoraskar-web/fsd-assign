React Profile Card

A single reusable ProfileCard component, rendered once per person with different data passed in through props.

How it works

ProfileCard accepts name, role, image, bio and tags as props. App holds an array of 6 people and renders one card per entry with .map(), so adding a new person never means writing new markup. useState powers the search box and the Connect button, and a photo that fails to load falls back to the person's initials.
